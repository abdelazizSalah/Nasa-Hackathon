# Nasa Hackathon

## Play Mission Forge

**Windows: clone this repo, then double-click [play/windows/MissionForge.exe](play/windows/MissionForge.exe).** No Python or GMAT installation is needed for Cached mode.

- [Start here: player README, controls, multiplayer and troubleshooting](play/README.md)
- [Complete handbook: mission, all choices, trade-offs, constraints and telemetry](output/pdf/mission-forge-complete-handbook.pdf)
- [Short successful-configuration guide](output/pdf/Successful_Congigurations.pdf)
- [Developer setup and project documentation](Space%20Mission%20Design%20Game/README.md)

The packaged executable targets 64-bit Windows. Linux/Arch needs a native build; see the player README and manual build workflow. For multiplayer, update every laptop to the same version and use the host's Wi-Fi IPv4 and room code.

## Screenshots

Explore the game from mission selection and learning to spacecraft design, validation and launch.

### Entry room and mission selection

Start at the Earth display, select Flood Watch and follow the progress guide to your next task.

![Entry room and mission selection](Space%20Mission%20Design%20Game/images/Spawning_Room.png)

### Controls and instructions

The welcome panel explains movement, mouse look, interaction, inventory and multiplayer controls.

![Controls and instructions](Space%20Mission%20Design%20Game/images/Instructions.png)

### Aerospace learning library

Explore twelve interactive books covering spaceflight, spacecraft systems and mission design.

![Aerospace learning library](Space%20Mission%20Design%20Game/images/Library.png)

### Cooperative multiplayer

Host a shared mission or join friends on the same Wi-Fi using the host address and room code; up to four players share engineering roles.

![Cooperative multiplayer](Space%20Mission%20Design%20Game/images/Network_Connectivity.png)

### Payload design

Choose the imaging sensor in the cyan Payload room, balancing science quality against power, mass, data production and cost.

![Payload design](Space%20Mission%20Design%20Game/images/Stage1.png)

### Power systems

Select solar arrays and battery capacity in the amber Power room to keep the spacecraft operating through sunlight and eclipse.

![Power systems](Space%20Mission%20Design%20Game/images/Stage2.png)

### Communications

Choose a radio in the violet Communications room and balance downlink speed against power demand, mass and budget.

![Communications](Space%20Mission%20Design%20Game/images/Stage3.png)

### Component choices and trade-offs

Compare option prices and specifications beside a rotating spacecraft preview and the shared design's resource values.

![Component choices and trade-offs](Space%20Mission%20Design%20Game/images/Component_selection_and_trades_off.png)

### Satellite integration and validation

Place the collected components, submit the mission plans and review the room display before the host approves readiness.

![Satellite integration and validation](Space%20Mission%20Design%20Game/images/Validation_and_launch_room.png)

### Mission Control and launch

Track all six contributions, review readiness, select the trajectory source and observation plan, then launch after approval.

![Mission Control and launch](Space%20Mission%20Design%20Game/images/Launch_dialog.png)
