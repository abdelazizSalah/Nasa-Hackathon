# Nasa Hackathon

## Play Mission Forge

**Windows: clone this repo, then double-click [play/windows/MissionForge.exe](play/windows/MissionForge.exe).** No Python or GMAT installation is needed for Cached mode.

- [Start here: player README, controls, multiplayer and troubleshooting](play/README.md)
- [Complete handbook: mission, all choices, trade-offs, constraints and telemetry](output/pdf/mission-forge-complete-handbook.pdf)
- [Short successful-configuration guide](output/pdf/Successful_Congigurations.pdf)
- [Developer setup and project documentation](Space%20Mission%20Design%20Game/README.md)

The packaged executable targets 64-bit Windows. Linux/Arch needs a native build; see the player README and manual build workflow. For multiplayer, update every laptop to the same version and use the host's Wi-Fi IPv4 and room code.
